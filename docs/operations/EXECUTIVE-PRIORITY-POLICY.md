## 1. Reglas de Derivación Basadas en Hechos Verificados

Las prioridades ejecutivas proyectadas para el día siguiente (`priorities_tomorrow`) deben ser **estrictamente explicables y basadas en hechos documentados**:

1. **Compromisos Post-Visita con Vencimiento Mañana (CORE-12):**  
   Si hay exámenes de laboratorio pendientes cuyos resultados llegan mañana, el sistema incluye: *"Seguimiento y entrega de resultados de laboratorio de [Paciente] (Compromiso Post-Visita)"*.
2. **Pacientes Crónicos y Cuidado Recurrente (CORE-09 y CORE-10):**  
   Si hay visitas de tratamiento o refuerzos vacunales agendados, el sistema incluye: *"Verificar stock biológico y cadena de frío para visitas de vacunación agendadas"*.
3. **Remisiones a Especialistas en Curso (CORE-11):**  
   Si hay pacientes remitidos a ecografía o interconsulta, se lista: *"Confirmar recepción de informe clínico de especialista para [Paciente]"*.
4. **Prohibición Expresa de Proyección Especulativa:**  
   Queda terminantemente prohibido incluir prioridades basadas en "posibles clientes que podrían llamar" o "visitas estimadas estadísticamente". Cada ítem debe contar con un ID de registro respaldado en base de datos.
