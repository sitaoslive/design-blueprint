# VET FREEDOM OS — APROBACIÓN Y PUBLICACIÓN DE TESTIMONIOS

## 1. Flujo de Publicación
1. **Consentimiento Informado:** Firma digital del tutor con selección de permisos (nombre, foto, historia).
2. **Revisión Médica:** Aprobación por parte de Dirección Médica para certificar que el relato respeta la ética profesional veterinaria.
3. **Publicación Controlada:** Despliegue en el portal Lovable.
4. **Despublicación Inmediata:** Si el tutor revoca su consentimiento, el sistema despublica el testimonio de forma automática e irreversible.
