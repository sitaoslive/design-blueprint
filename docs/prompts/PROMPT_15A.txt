Tu misión es implementar un módulo nuevo denominado:
VET LIVE DISPATCH & SMART ETA
Queremos convertir Vet Freedom OS en una plataforma de coordinación de visitas domiciliarias con una experiencia similar a las aplicaciones modernas de transporte y entrega.
La plataforma deberá permitir:
Configurar tipos de cita.
Definir duración predeterminada por servicio.
Modificar la duración durante la programación si está autorizado.
Registrar la duración aplicada al confirmar la cita.

Consultar la siguiente visita.

Mostrar ETA actualizado cuando existan datos suficientes.
Detectar retrasos.
Calcular impacto sobre citas posteriores.
Avisar internamente a coordinación.
Preparar comunicaciones automáticas a propietarios afectados.
Mostrar una pantalla privada tipo Uber al propietario.
Registrar todo en un historial verificable.
El objetivo es que la operación sea predecible, transparente y muy fácil de supervisar.

6. SEPARAR CUATRO TIPOS DE TIEMPO
No utilizar un único campo para todos los cálculos.
A — DURACIÓN DEL SERVICIO
Tiempo previsto para la atención.
B — BUFFER DE PREPARACIÓN
Tiempo necesario antes del servicio.
C — BUFFER ADMINISTRATIVO
Tiempo para registro, documentación y cierre.
D — TIEMPO DE DESPLAZAMIENTO
Tiempo estimado de viaje entre visitas.
Regla
El tiempo total de ocupación se calcula según reglas aplicables, sin contabilizar dos veces buffers incorporados en otra duración.
La duración visible para el propietario debe ser la aprobada para su visita, no necesariamente la suma de todos los buffers internos.

"Tiempo restante no disponible".

El profesional puede informar una expectativa de finalización revisada sin alterar el registro oficial de duración programada.
