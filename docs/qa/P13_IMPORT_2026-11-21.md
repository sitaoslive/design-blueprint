# P13 lote B — revisión de importaciones y calidad

## Entregado y probado
- Secciones 25–30 ampliadas reutilizando el catálogo/control administrativo, guardArea, lectura account-scoped de Finance y visits. Cinco superficies: OKVET, importar, conciliación, conflictos y datos/calidad.
- Wizard de nueve pasos: autorización declarada, tipo de citas, preview, mapeo, formato, duplicados, comparación, revisión y resultado. Archivo en memoria de la página; no localStorage ni persistencia oficial. Se descarta al salir, recargar o cambiar de cuenta.
- Parser Papa Parse: CSV con comillas/separadores, encabezados normalizados y sugerencias solo inequívocas. Límites 1 MB, 40 columnas, 2000 registros. Columnas/valores requeridos, fechas Bogotá, estados, referencias repetidas y filas desalineadas.
- Conciliación solo por ID/referencia inequívoca; diferencias de mascota/profesional/fecha/estado/referencia y conflictos ID vs referencia. Nombre similar no identifica ni fusiona. MATCHED no significa VERIFIED.
- Calidad de visitas: datos faltantes/incorrectos, dirección, responsable y referencias oficiales repetidas/faltantes. No modifica registros. Cobertura de propietarios/contactos/servicios/compromisos no certificada.
- Seis contratos de importación/reconciliación registrados en tablero existente. Esquemas de revisión/recibo/error; requestOkvetImport falla cerrado. No endpoints ni API OKVET inventados.

## Ejecución verificable
| Caso | Resultado |
|---|---|
| Cuenta autenticada temporal Administración | /admin/okvet/importar abierto; fuentes de visits realmente leídas bajo permisos existentes |
| Autorización ausente | Selector de CSV deshabilitado |
| Encabezados duplicados | Error visible; Siguiente deshabilitado |
| Mapeo sin ID mascota | Campo obligatorio faltante visible; mapeo ajustado por usuario |
| Dos referencias iguales | Hallazgos para ambas filas; revisión no permite pasar al resultado |
| Nueve pasos con archivo sintético válido | Recorridos; coincidencia UNMATCHED visible en fuentes actuales, no selecciona cita |
| Contrato protegido | BACKEND_UNAVAILABLE visible: archivo no enviado, cita no modificada |
| Inmutabilidad | Snapshot autorizado completo de visits antes/después idéntico; cero solicitudes de escritura al Data API en el flujo |
| Recarga | Archivo y consentimiento descartados; no importación recuperada ficticia |
| Seis rutas en 360/390/768/1366 | Sin overflow horizontal, cero pageerror |
| Cuenta autenticada sin Administración | /admin/okvet/importar → /sin-acceso; input de archivo no renderizado |
| Demo móvil | Mapeo y conflictos recorridos en 360 px sin login; doce perfiles demo presentes |
| Tests | 415 aprobados en 26 archivos; 30 nuevos de importación + 6 previos P13; build OK |

Pruebas del dominio comprueban además MATCHED, CONFLICT, fechas/profesionales distintos, referencias locales duplicadas, IDs contradictorios, CSV malformado y las fechas con zona Bogotá. Estas pruebas no son certificación oficial del proveedor.

## Evidencia repetible
- `src/test/system-import-p13.test.ts`: 30 casos; ejecutar `bunx vitest run src/test/system-import-p13.test.ts`.
- Scripts guardados: `docs/qa/scripts/p13-import-flow.py`, `p13-import-access.py`. Leen la sesión de prueba mintada en sandbox, sin credenciales en código. El primero crea CSV temporales desde una lectura autorizada y el segundo los reutiliza.
- Capturas inspeccionadas en sandbox `/tmp/browser/p13-import/`: comparación, resultado bloqueado, calidad móvil, mapeo/conflictos demo móvil. No son adjuntos ni archivos persistentes del proyecto.
- Un test inicial detectó que Papa Parse avisaba separador desconocido en CSV de una columna: se permitió únicamente ese aviso, sin ignorar errores de comillas/filas. Batería final íntegra aprobada.
- No se insertaron datos de negocio, no hay fixtures persistentes por limpiar. Solo cuenta temporal/perfil de prueba; perfil retirado para probar denegación. Demos e históricos intactos.

## Límites y siguiente lote
1. Procesamiento persistente, vinculación, revisión oficial/assignación/cierre de conflictos y auditoría real: requieren contratos Antigravity con autorización por operación, idempotencia, versiones y evidencia verificable. Botón local no los sustituye.
2. Otros tipos de exportación, revisión de propietarios/contactos/servicios y reglas por organización pendientes; no se interpretan datos clínicos ni financieros como citas.
3. Las páginas conciliación/conflictos muestran hallazgos locales y acceso al comparador de archivo; no existe bandeja oficial persistente de casos.
4. Resto P13: cambios de configuración versionados/simulados, monitor de eventos/errores, credenciales, backup/restauración, costos, retención y matrices maestras. Autoridad y fuentes externas pendientes donde corresponda.
5. Lanzamiento y totalidad de los 112 casos P13 / 170 AT originales / 224 comportamientos no certificados. No producción, integración externa ni dispositivo físico probado.

Sin migraciones, cambios de RLS, nuevas credenciales, conexión OKVET, scraping, sincronización, mensajes ni confirmaciones externas.
