# VET FREEDOM OS — PRIVACIDAD Y PROTECCIÓN DE DATOS DEL TUTOR

## 1. Cumplimiento Normativo (Ley 1581 de 2012 de Colombia)
1. **Consentimiento Previo y Expreso:** Ningún tutor recibe encuestas o solicitudes de retroalimentación sin contar con el consentimiento previo verificado en **VET-CORE-05**.
2. **No Revelación Pública de Datos Privados:** Los comentarios de encuestas internas son estrictamente privados y confidenciales. No se exponen en páginas web ni redes sociales sin autorización explícita.
3. **Derecho de Supresión (Opt-out):** Todo mensaje incluye una opción clara para pausar o detener las encuestas. Al solicitarlo, se activa una supresión en `customer_experience_sensitive_suppressions`.
